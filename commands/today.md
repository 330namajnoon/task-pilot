description: What you worked on today and for how long
---

Call `report` with `period: "today"` and present it to the user in their language: total worked, time per task and per type, and the time without a task.

Then ask whether the times look right. If the user corrects something or mentions work done outside Claude Code (meetings, calls, reviews), record it with `time_adjust` using exactly the amounts they give — never invent them.
